# 🎓 Student Performance & Placement Analytics

## 📊 Project Overview
This project is an interactive **Power BI dashboard** designed to analyze student performance, attendance, placements, and internships.

The dashboard transforms raw student data into meaningful insights and helps understand academic performance and career outcomes.

---

## 🎯 Key Insights

- 👨‍🎓 **Total Students:** 1,000
- 📈 **Average Attendance:** 78.33%
- 📝 **Average Marks:** 81.99
- 💼 **Total Placements:** 430
- 🎯 **Total Internships:** 347

---

## 📊 Dashboard Features

- Student distribution by gender
- Student distribution by department
- Average attendance by course
- Average marks by subject
- Placement analysis by company
- Placement status analysis
- Internship status analysis
- Student analysis by semester
- Interactive filters for Gender, Department, and Semester
